## 今回の追加静的解析: $0799 系

### 1. scalar `$0799` ではなく indexed `$0799,X` が本線
ROM全体をスキャンしたところ、以下は 0 件だった。

- `AD 99 07` = `LDA $0799`
- `8D 99 07` = `STA $0799`
- `AF 99 07 7E` = `LDA $7E0799`
- `8F 99 07 7E` = `STA $7E0799`

一方、`$0799,X` は多数見つかった。

- `BD 99 07` = `LDA $0799,X`: 23 件
- `9D 99 07` = `STA $0799,X`: 20 件

したがって、260510Y の `STA $0799 / LDA $0799 / AND #imm / BNE skip` は、実ROM上では少なくとも **slot indexed field base `$0799,X` の簡略表記** として読み替える必要がある。

### 2. SKIP_MASK=$80 の静的根拠が増えた
`89:BA70` 近傍に `$0799,X` の bit7 を直接見る処理がある。

```asm
89:BA70  DA          PHX
89:BA71  AE 96 13    LDX $1396
89:BA74  F0 19       BEQ $BA8F
89:BA76  BD 99 07    LDA $0799,X
89:BA79  10 14       BPL $BA8F        ; bit7=0なら抜ける
89:BA7B  BD 99 07    LDA $0799,X
89:BA7E  29 7F       AND #$7F         ; bit7を消す
89:BA80  1A          INC A
89:BA81  9D 99 07    STA $0799,X
89:BA84  AD 95 13    LDA $1395
89:BA87  D0 06       BNE $BA8F
89:BA89  DE 99 07    DEC $0799,X
89:BA8C  38          SEC
89:BA8D  80 01       BRA $BA90
89:BA8F  18          CLC
89:BA90  FA          PLX
89:BA91  60          RTS
```

また `89:BAC8` 近傍には同じ `$0799,X` に bit7 をセットする処理がある。

```asm
89:BAC8  BD 99 07    LDA $0799,X
89:BACB  09 80       ORA #$80
89:BACD  9D 99 07    STA $0799,X
```

これにより、`SKIP_MASK=$80` は「仮説」から一段上げて、**$0799,X 系 slot field の bit7 制御として静的根拠あり**に更新できる。

ただし、この bit7 が Goal13 の最終 visibility skip そのものか、slot state / cooldown / phase flag なのかは runtime join が必要。

### 3. bank87 では `$0799,X` 初期化・slot field 操作が多い
bank87には `$0759,X`, `$0799,X`, `$07D9,X`, `$0819,X` などの並列slot field初期化が見える。
例:

```asm
87:8119  A9 E0       LDA #$E0
87:811B  9D 59 07    STA $0759,X
87:811E  A9 87       LDA #$87
87:8120  9D 99 07    STA $0799,X
87:8123  A9 FF       LDA #$FF
87:8125  9D D9 07    STA $07D9,X
```

このため `$0799` は singleton visibility staging ではなく、**slot structure の1列**として扱うのが安全。

## 追加結論
- 260510Y の「最重要命令窓」は完全には外れていないが、探索シグネチャは修正した方がよい。
- 旧探索: `LDA $0799 / AND #imm / BNE skip`
- 新探索候補: `$0799,X` の bit7 を見る/立てる/消す処理、特に `BPL/BMI`, `AND #$7F`, `ORA #$80`, `DEC/INC $0799,X`。
- 今回の最有力候補は `89:BA70..BA91` と `89:BAC8..BACD`。
- 次は `89:BA70` の caller (`89:BA36`, `89:BA48`) と `89:BAA9`/`89:BADD` 周辺を追い、`$1395/$1396`, `$12DF..$12E7`, `$030B/$030D` が Goal13 visible cutoff と結びつくか確認する。
