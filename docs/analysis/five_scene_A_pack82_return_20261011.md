# 新桃太郎伝説：5か所のA操作後方向試験とpack0x82の世界帰還

2026-10-11 / zin1985/shinmomo

## 結果

世界から実機入場済みの5パック（0xBD、0xB9、0xAB、0x82、0x60）を、隠れた専用BizHawkの保護ステートから再調査した。

- 通常Aを8フレーム＋無入力64フレーム実行し、Down/Up/Left/Rightの4方向を96フレームずつ試した。合計5シーン・20方向の本物のゲームパッド試験。
- 鬼が島pack0xBD、虹の洞窟pack0xB9、怨みの洞窟pack0xABは4方向とも座標移動したが、同じ方向の短い直進ではマップ切替なし。Aが移動可否の原因とまでは立証していない。
- 村系pack0x82とpack0x60ではA1回後の4方向は座標固定のまま。
- 村系2件を別途A8＋無入力20の12回で進めた結果、pack0x82はDown96で世界pack0x4Cに帰還。pack0x60は現在の状態ではまだ帰還なし。
- pack0x82の帰還先世界XYは(175,189)。独立した復帰実験と追加無入力360フレームで安定確認。既存のROM入口候補catalog_transition_0791の元世界座標(175..176,189)と一致。
