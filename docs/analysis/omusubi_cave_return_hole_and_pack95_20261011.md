# おむすびころりん：世界への帰還・縦穴・次の洞窟区画0x95の実機確認

2026-10-11 / zin1985/shinmomo

## 検証条件

非表示の専用BizHawkを使用。元のユーザー用エミュ状態は
最後に必ず復元した。ROM、通常セーブデータを変更せず、
生WRAMフレームログ、スクリーンショット、解析用ステートを
専用PCのローカル領域だけに保存した。

洞窟への最初の入場は、世界マップ上で座標チートにより
(47,200)へ移動し、通常のSNES Up操作で(47,199)の
入口イベントを踏んだもの。その後の洞窟実機検証で、
「普通に世界からここまで歩ける」は一切証明していない。

## 1. 洞窟の出口から世界へ帰還

既存の洞窟到着ステート：cfg_t08_l092_v2、pack0x91、(71,59)。

通常操作でDownを50フレーム実行して(71,61)へ移動。
次にUpを35フレーム押すと、(71,59)の階段状タイルに
フレーム663402で触れ、663417にpack0x91→世界pack0x4Cに変わった。

world座標(47,199)への確定は663532と遅く、
前半120無入力フレームでは着地後の観察が6フレームしかない。
従来の8フレーム安定要件で拒否されたため、
無入力120フレームをさらに1本つないで検証した。
合計の観測終了663657、確定後126フレーム安定。
生VM領域$126E/$12B4の0x4Cへの収束は663451。

tools/python/audit_transition_phases.pyに
extra_neutral_trace / --extra-neutral-traceを追加し、
2本目の無入力窓も1本目から全WRAM項目/フレームで
厳密につながる場合だけ結果を認める。
これを確認する回帰テストも用意した。

派生証拠：
data/maps/transitions/omusubi_cave_world_return_verified_20261011.json

「洞窟→世界」は新たな1つの実測接続としてViewerに登録。
ただし帰還座標(47,199)は、今回の
**座標チートから開始した世界入場履歴に依存**する。
別セーブでも必ず同じ座標へ戻るとは扱わない。
実行CPU命令アドレスや全物語フラグは未確認。

## 2. 構造タイル調査

ROM復元済みのt08/l092マップには、
メタタイルID32（階段／入口状）が
(56,38)、(88,38)、(71,42)、(55,58)、(71,59)の計5マス。
ID30（黒い穴状）は(75,53)、(87,56)の2マス。

洞窟内の座標ワープは、新しい
tools/remote_lab/create_hidden_scene_warp_state.ps1
を使い、元のpack0x91を検証して
WRAM $1573 / $157Dだけ変更したローカル解析ステートを作成。
全変更を再読取し、前のエミュ状態へ必ず戻す。
上書きは禁止、正規の徒歩経路の証明にはしない。

ID32のうち(71,59)は通常の洞窟内歩行から確認済み。
他の(56,38)、(88,38)、(71,42)、(55,58)は
解析用座標ワープで南隣に寄せてからUp入力を行うと
世界pack0x4Cの(47,199)へ帰還した。
ただし独立の他セーブでも同じ結果になるとは限らない。

黒い穴ID30の(87,56)でも、座標ワープ後のUp入力で
世界pack0x4Cへ復帰。一方、(75,53)の穴は全く別の
内部移動イベントを発火させた。同じタイル絵でも
イベントの働きが一律とは限らない。

## 4. 縦穴先から新しいpack0x95へ

縦穴の落下後に無入力60フレームで位置を確認し、
(70,26)から通常Right40フレーム。

| 観測 | フレーム | pack / XY |
| --- | ---: | --- |
| 右へ移動、(71,26)に到達 | 663918 | 0x91 / (71,26) |
| マップ切替 | 663933 | 0x91→0x95 |
| 生VM領域$126E/$12B4の収束 | 663967 | 0x95 |
| 次の洞窟区画に着地 | 664018 | 0x95 / (22,8) |
| 無入力120フレーム後 | 664076 | 0x95 / (22,8) |

pack0x95はROM境界カタログの
cfg_t08_l096_v2、tileset8/layout96に一致。
既存候補catalog_transition_0171は、
静的命令候補CC:D377、destination=0x95、
到着(22,8)だがsourceが未確定だった。
今回の実機の出発マップcfg_t08_l092_v2を、
この**既存候補のsourceだけ**に結びつけた。

CPUでCC:D377が直接実行された証拠はない。
従来のstrong_candidate信頼度と
navigable_now=false／実行条件unknownを維持。
pack0x95の固有地名やダンジョン階数は未確認。
