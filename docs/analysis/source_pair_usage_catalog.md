# Source-pair usage catalog

Updated: 2026-09-26

## Purpose

The C7:0000 master entries overlap, so complete text/resource inventory cannot be built by treating the next master pointer as a family boundary.

The correct unit of evidence is an actually selected:

`(source_family, subindex)`

This catalog combines script-pack A4 operands, direct source-selector calls, special overrides, and historically confirmed static pairs.

## Script-pack bridge

The CA:C000 24-bit pointer table and C7:0000 source-family table share the same global index for real script packs.

- CA indices 0x00..0x13 are reserved/zero slots.
- real pack intervals are 0x14..0xF9.
- CA index 0xFA is the final boundary/sentinel.
- for real packs, CA pack interval index == C7 source-family index.

Example:

- global index 0x16
- script pack CB:01F9..CB:0FFC
- source-family root C7:8D13

This connects the script/event pack to the source reader without guessing a separate family map.

## A4 source-selection semantics

Historical mini-VM analysis establishes:

`A4 <operand>`

as a source subindex selection path.

The current static scanner accepts the high-confidence forms:

- `A4 xx B0`
- `A4 xx C0 B5`
- `A4 xx B2 dd A4 yy`

The family is the current CA:C000 pack index; the A4 operand is the source subindex.

Candidate pairs are accepted only when the real source reader can reach the requested subindex. This rejects false-positive A4-like byte patterns in non-script payload.

Two packs, family 0xF2 and 0xF7, produced 88 raw pattern candidates that failed source-reader reachability and are therefore excluded.

## Direct display/source calls

A separate static pass over C4:A02D / A0B9 / A0C3 adds 19 exact pairs whose family and subindex can be resolved statically.

C4:A02D is especially useful because it calls C4:9DE5, already identified as the next-display-token reader. Five exact A02D pairs are therefore classified as display-pipeline source usage.

They are not automatically labelled dialogue. One selected record is empty, and the others may represent UI/system text as well as dialogue.

## Confirmed cross-checks

### Dialogue

Family 0x4F / subindex 0:

- family root C8:A7DC
- mode 02
- selected payload C8:A7DD
- previous v33 restoration contains player-visible dialogue
- current catalog marks this pair confirmed_dialogue

Family 0x4F / subindex 1 is retained as strong_dialogue.

### Non-dialogue

Family 0x16 is used by weapon/descriptor logic.

Confirmed subindices include 0x82, 0x83, 0x84, 0xC1, 0xC2 and 0xC8.

The 0xC8 selection lands at C7:A64D, crossing later master roots. This is the key proof that master entries are overlapping checkpoints rather than bounded family blobs.
