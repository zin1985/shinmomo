# おむすびころりん：2区画間の往復と階段タイルの方向別検証
2026-10-11 / zin1985/shinmomo

## 実験の前提

非表示の専用BizHawkで、前回確認済みのpack0x95
（cfg_t08_l096_v2）到着(22,8)の解析ステートを使用した。
世界から洞窟へ入る最初の過程には解析用座標ワープを利用したため、
全経路が普通に徒歩で通行可能とは断定しない。
ROM、ユーザーの通常セーブ、可視のエミュは変更していない。
原スクリーンショット・生フレームログ・解析ステートはローカル専用で、
実験後は専用エミュを元の状態へ復元済み。

## 1. pack0x95の入口から0x91へ通常操作で帰還

最初の着地点(22,8)からSNES Down11フレームで(22,9)へ移動し、
続けてSNES Up20フレームで(22,8)へ戻った。
さらに120フレーム無入力を2回連続させて観測した。

| 出来事 | フレーム | pack/XY |
|---|---:|---|
| 出発 | 664076 | 0x95 (22,8) |
| Down終了 | 664087 | 0x95 (22,9) |
| Upで階段タイルに再接触 | 664095 | 0x95 (22,8) |
| pack切替 | **664110** | 0x95→0x91 |
| $126E/$12B4が0x91に収束 | **664145** | 0x91 |
| 着地確定 | **664196** | 0x91 (71,26) |
| 観測終了 | 664347 | 0x91 (71,26) |

到着後152フレーム安定した。イベントの操作には
通常のSNESコントローラを使用し、実行中はWRAM座標操作をしていない。

既存静的候補 catalog_transition_0194 は
ROMのscript pack0x95、terminal opcode0x56候補 CC:DA1A、
行先pack0x91の一意な候補。今回、
出発 cfg_t08_l096_v2、到着 cfg_t08_l092_v2 (71,26)と
実機座標の整合を確認したので、この既存候補の
sourceとdestinationを追加した。ROM opcode PCが実際に
実行されたとは確認できていないため、
元のstrong_candidateと物語ゲートunknownは維持。
runtime_reverse_stair_proofとして実測情報を明示している。

再現器:
- tools/python/verify_pack95_reverse_stair.py
- tools/python/attach_pack95_reverse_stair.py
- scripts/test_pack95_reverse_stair.py

派生証拠:
data/maps/transitions/omusubi_pack95_reverse_stair_verified_20261011.json

## 2. もう一方の階段状タイル(22,31)

復元ROMマップ t08_l096 のメタタイルID31は
(22,8)と(22,31)の2か所。
別の解析用ステートで、pack0x95のまま
座標だけ(22,32)と(22,30)へそれぞれ配置した後、
最後の一歩を通常のSNES入力で検証した。

- (22,32)からUp27フレームで(22,31)を踏み、
  (22,30)へ抜けた。初接触は**664090**。さらに120フレーム無入力でもpack0x95。
- (22,30)からDown29フレームで(22,31)を踏み、
  (22,32)へ抜けた。接触フレーム**664090**。
  120フレーム無入力でもpack0x95。

この2方向、この解析状態ではpack切替は観測されなかった。
全ストーリー条件で発火しない、あるいは無条件通過可能とは
意味しない。

ROMのcatalog_transition_0183はpack0x95 (22,31)を
行先とする静的候補。階段に見える地形が
他マップからの着地点という可能性はあるが
原作での実行PCや元マップは未確定。
ソース出口としてグラフを昇格させない。

派生証拠:
data/maps/transitions/pack95_ladder22_31_no_switch_probe_20261011.json

## 3. 現時点の洞窟内部系列

- 世界pack0x4Cの(47,200)に解析用座標ワープし、
  通常Upで(47,199)の入口を踏んでpack0x91の(71,59)へ
- pack0x91の黒い穴(75,53)に解析用近接ワープ後に通常Up
- 同じpack0x91内で(70,8)へ転送され、
  無入力の自動下降で(70,26)に停止
- 通常Rightで(71,26)を踏みpack0x95の(22,8)へ
- 通常DownとUpで(22,8)を踏み直し、
  pack0x91の(71,26)へ復帰

最初のチート配置、洞窟内の近接チート配置と
通常操作によるイベント発火を区別する。
