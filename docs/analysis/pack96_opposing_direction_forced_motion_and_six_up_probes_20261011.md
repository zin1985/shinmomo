# 新桃太郎伝説：上下どちらでも下降する洞窟pack0x96と6シーンの再調査

2026-10-11 / zin1985/shinmomo

## 検証条件

前回の20種類のシーン帰還試験のうち、Down72フレームでは世界に戻らなかった6種類だけを選び、
実機入場済みの解析セーブステートを個別にロードして、同じシーン到着位置から通常のSNES Up72フレームを送信した。
入力前に12無入力フレーム、入力後に120無入力フレームを記録した。
各試験で専用非表示BizHawkの元ステートを保存・復元し、入力操作中にWRAMの座標を書き換えていない。

元の世界から洞窟・村へ入るステート作成時には、世界の入口1マス手前への解析座標ワープを利用している。
そのため通常の徒歩だけで元のシーンに到達できることや、異なるストーリー状態での挙動は立証しない。

## pack0x96での新しい発見：上キー・下キーの位置履歴が完全一致

元の実機入場座標pack0x96 / cfg_t09_l098_v2 の(39,17)から、
別々にDown72とUp72を試行。どちらも前後の無入力窓を含む204フレームを記録した。

入力ボタンは正反対であるにもかかわらず、同一フレームの位置（pack/XY）は
**204/204件すべて一致**した。

Y=18～24の7段階の座標更新が、それぞれ9フレーム間隔で発生。
他方向の入力より優先される下降動作が観測されるが、
イベントスクリプトによる強制歩行、地形物理、モード切替などの正確な原因は未解読。
SNES CPU実行PCの直接記録もない。

**確認したのは、この保存ステートとこのフレーム区間での位置一致だけ。**
別のセーブや到着状態でも同じ強制下降になるかは今後検証が必要。
